# Localens 首版设计

已确认目标：Go + Wails 跨平台桌面应用，一个搜索框查找本地文件、文档和图片。视频首版提供文件名检索，视频语义分段后续实现。

采用 Wails v2 + 无构建依赖的原生 HTML/CSS/JS，Go 管理 SQLite、目录扫描、定期增量刷新、文件打开和预览。SQLite 保存元数据、可提取的正文、文本分块和 256 维向量。中文采用子串全文查询；英语多词 AND 匹配。初版小型语料向量采用精确余弦检索，以混合排名合并文件名、正文和语义命中。

推理采用持久 Python 子进程 JSONL 协议。模型采用 EmbeddingGemma 2，关闭音频编码器，支持文本/图片。模型显式启用，未安装时保留真实文件名和正文检索，显示安装指导和错误。网络只用于依赖与模型首次下载，资料不会发往在线推理服务。

扫描由用户选择目录启动，跳过隐藏目录、依赖目录和符号链接。重叠目录禁止添加，避免所有权混乱。文件逐个提交；取消或扫描失败时不执行删除清理。删除目录清除该目录的索引，不删除原始文件。预览和打开仅接受已索引文件，并重新检查文件仍处于所选目录之内。

验证：Go 集成测试覆盖中文正文搜索、文件名优先、类别过滤、增量变化与删除、持久化、取消及路径边界；推理协议测试覆盖错误/维度/异常值。构建原生 macOS 应用，进行 UI 冒烟验证。真实模型推理测试如遇兼容性/下载限制，记录明确状态。

限制：初版不是 NTFS MFT 索引器；首次内容索引比 Everything 慢。PDF 正文需要 pdftotext；DOCX 提取正文；扫描件 OCR、视频语义、ANN 向量索引和全局快捷键暂不实现。

## 用户修正：Spotlight 界面

用户明确拒绝三栏管理器界面，改为 Spotlight 风格：无边框透明悬浮条，默认仅搜索框，输入后展开结果。↑↓ 选择、Enter 打开、Esc 收起。目录与模型操作移入设置。macOS Option+Space 全局唤起，其他平台 Ctrl+Alt+Space，后台索引在窗口隐藏后持续。预览按需展开，不常驻侧栏。
